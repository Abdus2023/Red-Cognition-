# Conformance profiles

§18 labels the following profiles but, due to CADFP terminology (CONFLICT-001/002), does not establish unambiguous CFCKEP requirements. There is no profile-to-REQ mapping, implementation, or test evidence.

| Profile | Text in §18 | Requirement mapping | Status |
|---|---|---|---|
| Minimal | Local registration and discovery | ambiguous / CADFP-like | UNVERIFIED |
| Developer | Minimal + health monitoring | ambiguous | UNVERIFIED |
| Distributed | Developer + cross-node discovery | ambiguous | UNVERIFIED |
| Enterprise | Distributed + policy enforcement + audit | ambiguous | UNVERIFIED |
| Federation | Enterprise + cross-domain trust negotiation | partially related, still ambiguous | UNVERIFIED |
