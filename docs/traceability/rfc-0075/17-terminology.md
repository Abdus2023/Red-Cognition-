# Terminology consistency

| Term | RFC-0075 meaning | Other meaning / consistency |
|---|---|---|
| CFCKEP | federation collaboration and governed knowledge exchange | §15–19 say CADFP: **No** |
| CADFP | not defined as CFCKEP term | RFC-0054 Cognitive Agent Discovery and Federation Protocol: **No** |
| Federation / domain / CogOS | cross-domain collaboration participants | RFC-0041/0054 context; broadly compatible, boundaries not defined: unresolved |
| KnowledgeExchange / KnowledgeView | canonical transfer / optional governed view | no cross-RFC schema mapping: unresolved |
| Trust / capability / provenance | explicit trust; gates; extended chain | RFC-0006/0022/0074 semantic anchors; field semantics unresolved |
| Agreement / policy / event | federation contract / rules / record | event relation to RFC-0018/0046 unresolved |
| Artifact / Knowledge Object | `KnowledgeObjects` field only | scope/type undefined: unresolved |
