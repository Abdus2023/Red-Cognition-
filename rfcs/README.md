# RFC Corpus

The RFC source artifacts remain in this directory under their existing filenames. They are indexed without normalization, relocation, or merging in [`docs/RFC-INDEX.md`](../docs/RFC-INDEX.md).

The index distinguishes separate files that share an RFC number (for example, specification and ratification-record artifacts). Header status and relationship data are reproduced from source and may conflict; see the relevant traceability/conflict documentation rather than treating the index as a resolution.
