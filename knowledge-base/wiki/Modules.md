# Modules

> Provenance: Corpus message #2, sub-message [12] ("The Cognitive Standard Library").

## The Cognitive Standard Library (sub-message [12])

Today's standard library contains functions for strings, files, networking, and mathematics. A Cognitive Red standard library might include modules such as:

**SN-083**

```
memory/
reasoning/
planning/
verification/
policies/
skills/
capabilities/
knowledge/
reflection/
agents/
events/
models/
```

These become as fundamental as today's `io` or `math` libraries.
